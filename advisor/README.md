# Advisor materials

## `expectation_checklist.csv`

The advisor expectations checklist, copied from the KSU advisor resource guide.
Each row is one action an advisor might take, rated by how much SwAT wants them to
take it / the advisor's willingness to perform such an action.

The `level` column uses this scale:

| Level | Meaning |
| ----- | ------- |
| 1 | Essential for the advisor to do |
| 2 | Helpful for the advisor to do |
| 3 | Nice, but the advisor does not have to do |
| 4 | Prefer the advisor not to do |
| 5 | The advisor definitely should not do |
